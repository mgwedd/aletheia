# Project memory

Concise, non-obvious rules for this repo. (Obvious stuff omitted on purpose.)

## Attribution / contribution
- **Michael Wedd is the sole contributor of record.** No Claude attribution in
  commits, PR titles, or PR bodies. No `Co-Authored-By: Claude`, no
  `Claude-Session:` trailer, no "Generated with Claude Code" footer.
- No model identifier (e.g. "Opus", model IDs) in anything pushed to the repo.

## Names & project generation
- Product/display name is **Aletheia**, but the Xcode target, scheme, and source
  dir are still **`SessionNotes`**, and the bundle-id prefix is
  **`com.sessionnotes`**. Don't "fix" this mismatch.
- **No `.xcodeproj` is checked in.** `SessionNotes/project.yml` is the source of
  truth; XcodeGen generates the project. Edit `project.yml`, not a pbxproj.
- Deployment target: **macOS 14**.

## Privacy / architecture invariants (non-negotiable)
- **PHI never leaves the Mac.** No analytics/telemetry/servers. Only outbound
  calls: update appcast check, opt-in model downloads, local Ollama at
  `127.0.0.1` — none carry PHI.
- **Apple Intelligence is intentionally disabled** via
  `Integrations.appleIntelligenceBlocked = true` (kept provably on-device). Don't
  re-enable without being asked.
- No third-party GitHub marketplace Actions; first-party deps only (weak supply
  chain is a hard no).

## CI / release
- Repo is **public → unlimited free standard runners incl. macOS**. Only "larger"
  (`-xlarge`) runners are billed. macOS runners can't be swapped for Linux.
- Runner-quota failures look like real CI failures: **job never ran, logs 404**.
  Don't treat that as a code regression.
- **CHANGELOG.md is generated by CI — never hand-edit it.** Manual edits cause
  merge conflicts across PRs. Versioning is conventional-commits → semver.
- `scripts/scan-secrets.sh` is a fail-closed leak gate (secrets + PHI filenames).
  Its `git grep` uses `-e "$PATTERN"` because patterns start with `-----BEGIN`.

## Conventions
- `AppSettings` pattern: UserDefaults-backed, `private enum Keys`,
  `@Published var x { didSet { defaults.set(...) } }`, all loaded in `init`.
- Repo **auto-deletes head branches on merge**; merging a base branch closes its
  child PRs. Sequence PRs to avoid CHANGELOG/shared-file conflicts.
- This Linux sandbox has **no Swift toolchain** (`swift`/`xcodebuild` absent):
  can't run XCTest here. Validate with bash tests + close review; CI compiles.
